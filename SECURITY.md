# Security

When reporting an issue, include the recipe ID and redacted `./setup.sh detect` output. Keep credentials, signing keys, complete private inventories, guest backups and generated plans out of public reports. Build logs may contain local paths and platform metadata; review them before sharing.

This is experimental host-administration tooling. Evaluate it on a disposable host with recoverable backups. Signature enforcement is retained, and remote source inputs are pinned and checked; unknown platforms are rejected.
